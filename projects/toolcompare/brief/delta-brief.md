# Delta brief — controlled growth system

Replace direct AI-to-file publishing with a persistent SQL job queue,
deterministic quality gate, source ledger, human review queue, cron worker and
database-first tool delivery.

Locked decisions: preserve the public brand and routes, target Hostinger, do not
deploy in this turn, and never publish AI output without explicit approval.

Affected surfaces: private management dashboard, tool generation API, tool
repository, sitemap, MySQL schema and environment contract.

Unaffected surfaces: public homepage art direction, existing comparison pages
and existing catalog content.
