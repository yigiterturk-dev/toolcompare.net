# ToolCompare.net

Alet/makine karşılaştırma ve katalog platformu (Next.js) — teknik özellik tabloları, filtreler ve affiliate/lead-gen.

## Kurulum
```bash
npm ci
npm run dev
```

## Scripts
- `dev`, `build`, `start`, `lint`, `test`
- `verify:claims`, `check:fiyat`, `check:izgara`, `check`
- `gsc:*` — Google Search Console yardımcıları
- `affiliate:sira`, `veri:paket`

## Yapı
- `src/`, `app.js` — uygulama
- `tools/`, `scripts/`, `projects/` — veri ve araçlar
- `tests/` — testler

## Test
```bash
npm test
```
